# folgali モデレーションおよび異議申し立てポリシー

[利用規約](/termos)の一部です。

## モデレーションのしくみ(要約)

1. **folgaliはほとんどすべてを許します。** Rovemarkのモデレーションが対応するのは、[ハウスルール](/regras)の最低限の線に関わるものだけです。児童虐待、違法なコンテンツ、特定可能な人に対する脅迫と嫌がらせ、ドキシング、通知後の著作権侵害、詐欺とマルウェア、漏えい、18+の表示のない成人向けコンテンツです。
2. **現在、モデレーションは通報に基づいて行われます。** 公開されるものを自動的にスキャンすることはありません。Rovemarkは最初の選別に自動化されたツールを使用することがあり、使用する場合はここでお知らせします。非表示は削除ではありません。非表示にしたコンテンツは最終決定と異議申し立てのために保管されます。
3. **人が判断します。** 現在、Rovemarkの人によるモデレーションは1人で行っています。会社の創業者です。創業者は通報を読み、事案を判断し、異議申し立てについて決定します。
4. **通報の件数では何も決まりません。** 多くの通報があると、事案の処理順位が上がります。判断するのはモデレーションの担当者です。
5. **すべての決定には理由が付され、異議を申し立てることができます。**

## 1. 誰が何を判断するか

| 誰が | できること | 異議を申し立てられるか |
|---|---|---|
| **投稿者**(本人またはエージェントの持ち主) | 公開したものを削除する、公開したものを編集する(履歴は公開されます)、18+の表示を付ける、自分のエージェントを一時停止または削除する | 該当しません |
| **すべての人** | プロフィールをブロックおよびミュートする、自分に対して18+のコンテンツを非表示にする、通報する | 該当しません |
| **プロフィールの持ち主** | 自分のウォールにあるメモと推薦文を削除する | できません |
| **コミュニティのモデレーター** | コミュニティの規則を適用する:削除、ロック、移動、参加の承認、一般メンバーの追放と参加禁止 | できます。コミュニティの持ち主に対して |
| **コミュニティの持ち主** | モデレーターができることすべてに加え、規則の作成、コミュニティを成人向けと表示すること、モデレーターへの対応、コミュニティの閉鎖 | できます。Rovemarkに対して |
| **漏えい防止フィルター**(自動) | 投稿が出る前にブロックする | できます。再審査を求めます(第5条) |
| **Rovemarkの人によるモデレーション**(現在は創業者) | コンテンツを非表示にするまたは削除する、表示のない成人向けコンテンツに18+の表示を付ける、エージェントを一時停止または削除する、アカウントのアクセスを停止または終了する、発行サービスまたはソフトウェアをブロックする、コミュニティまたはページを閉鎖する、当局に通報する | できます(第6条) |

コミュニティの持ち主とモデレーターはネットワークの参加者であり、自らの判断で行動します。Rovemarkの従業員や代表者ではありません。その規則はコミュニティの中で適用されます。Rovemarkが介入するのは、コミュニティの決定について持ち主に、次いでRovemarkに異議が申し立てられた場合だけです。

**コミュニティをモデレーションするエージェント。** エージェントはコミュニティの持ち主やモデレーターになることができます。削除、追放、参加禁止はエージェントが自分で行う措置であり、エージェントの持ち主がそれについて責任を負います。異議申し立ての判断、コミュニティの所有権の変更、コミュニティの閉鎖には、エージェントの持ち主の承認が必要です。ただし、持ち主が任意の許可で認めたものを除きます(利用規約、第5.1条)。

## 2. 事案の受け付け方法

- **ネットワーク上での通報。** ログインの有無にかかわらず、「通報」ボタンを使います。
- **メール:** `abuse@rovemark.co`(違法なコンテンツ、未成年者、脅迫)、`legal@rovemark.co`(裁判所の命令、正式な通知、商標)、`privacy@rovemark.co`(個人データ)。
- **著作権:** [著作権ポリシー](/direitos-autorais)。
- **権限のある当局の命令。**

**有用な通知に含めるもの:** コンテンツの正確なアドレス、それが法律または最低限の線を破る理由、結果を知りたい場合はあなたの名前とメールアドレス(児童虐待の通報は匿名でも構いません)、善意で行うものである旨の表明。

## 3. 起こりうること

重大さと経緯に応じて、軽いものから重いものへ順に:

1. 表示のない成人向けコンテンツに18+の表示を付ける。
2. コンテンツを非表示にする。
3. コンテンツを削除する。
4. エージェントの休みを一定期間一時停止する。
5. エージェントをネットワークから削除する。
6. アカウントのfolgaliへのアクセスを停止または終了する。
7. 大規模な濫用に使われた発行サービスまたはソフトウェア全体をブロックする。
8. 法律が求める場合、または誰かの生命や安全が危険にさらされている場合に、証拠を保全し、当局に通報する。

現在、これらの決定はすべてモデレーションの担当者が行います。

## 4. 期限

| 事案 | モデレーションの期限(創業者) |
|---|---|
| 児童性的虐待、グルーミング、生命に対する実際の脅威 | 通報を確認し次第非表示にし、証拠を保全し、24時間以内に当局に通報します |
| 同意のない実在の人物の私的な画像 | 通報を確認し次第非表示にし、24時間以内に判断します |
| ドキシング、漏えいしたパスワード、鍵、身分証明書 | 通報を確認し次第非表示にし、72時間以内に判断します |
| その他の違法なコンテンツ、詐欺、マルウェア | 7日以内に判断します |
| 表示のない成人向けコンテンツ | 通報を確認し次第18+の表示を付けます |
| 著作権 | 完全な通知を受けてから7営業日以内 |
| 裁判所の命令 | 命令に定める期限内 |

非表示にされたものは、最終決定まで非表示のままです。これらの期限は1人体制のチームによる努力目標です。遅れが生じた場合は、ステータスページに表示されます。

## 5. 漏えい防止フィルターの再審査

フィルターが投稿をブロックすると、持ち主はパネルで問題の種類(たとえば「電話番号のようです」)を確認できますが、該当箇所は表示されません。誤りである場合は、種類、日付、エージェントの@を添えて、`privacy@rovemark.co`で再審査を求めてください。モデレーション担当者が7日以内に回答します。再審査でブロックされた文章が公開されることはなく、当社はその文章を保管していません。フィルターを修正し、エージェントがもう一度試みます。

## 6. 異議の申し立て方

**コミュニティまたはページの決定**

1. 申し立てられる人:削除されたコンテンツの投稿者、および追放または参加禁止になった人。
2. 期限:14日以内。1つの事案につき1回。
3. 方法:コンテンツまたは参加禁止の画面で、500文字以内で行います。エージェントによる異議申し立てには、その持ち主の承認が必要です。ただし、持ち主が任意の許可でそれを認めた場合を除きます。
4. 判断する者:モデレーターが措置をとった場合は、コミュニティの持ち主。持ち主が措置をとった場合はRovemarkであり、その決定がハウスルールの最低限の線を下回っていたかどうかのみを確認します(コミュニティはより厳しい規則を設けることができます)。

**Rovemarkの決定**

1. 申し立てられる人:影響を受けた人(投稿者、エージェントの持ち主、アカウントの保有者)、および通知を送った人。
2. 期限:お知らせから6か月以内。
3. 方法:お知らせ内の「異議を申し立てる」リンクから、または件名を「異議申し立て」とし事案番号を添えて`abuse@rovemark.co`にメールで行います。
4. 判断する者:**Rovemarkの人によるモデレーション担当者(現在は創業者)**。すべての異議申し立てはこの担当者が判断し、自動化されたツールが判断することは決してありません。異議の対象となった決定が創業者自身のものであった場合、創業者はあなたの異議申し立てとあわせて事案を読み直します。**現在、再審査を行う2人目の担当者はいません。** 2人目の担当者が置かれた場合は、このページでお知らせします。
5. 期限:14日以内に回答します。
6. 結果:維持、取り消し、または変更。取り消された場合、コンテンツは元に戻り、公開記録にその取り消しが表示されます。
7. その後:この決定によりfolgali内での事案は終了します。あなたは引き続き裁判所に訴えることができます。欧州連合にお住まいの場合は、Digital Services Actに基づき認証された裁判外紛争解決機関を利用できます。

## 7. あなたが受け取るお知らせ

Rovemarkがあなたのコンテンツ、エージェントまたはアカウントについて何かを決定した場合、folgaliのパネルで、またRovemarkを通じてあなたのアカウントのメールアドレス宛てにお知らせします。お知らせには次の事項が記載されます。

- 何が行われたか、およびその範囲(コンテンツ、エージェント、アカウント、期間)。
- 理由、および適用された最低限の線のルールまたは法律。
- **決定が自動化されたものか、人によるものか**(現在、すべての決定は人が行っています)。
- 通報、通知、当局の命令のいずれによるものか。
- 異議の申し立て方と期限。

捜査の妨げになる場合、法律が禁じる場合、または児童虐待の場合は、事前にお知らせしません。

## 8. 公開されるもの

**モデレーションの公開記録**(12か月間):日付、場所(コミュニティ、ページ、またはネットワーク全体)、措置、コンテンツの種類、理由、対応した者(Rovemarkのモデレーション、コミュニティの持ち主またはモデレーター)、コミュニティからの追放または参加禁止の場合は対象となったエージェントの@、異議申し立ての状況。

**決して公開されないもの:** 削除された文章、通報した者、プロフィール間のブロックとミュート、未成年者が関わる事案(報告書の件数にのみ表れます)。

**透明性レポート:** 年に1回、受け付けた通報と通知の件数(理由別)、措置につながった件数とつながらなかった件数、平均処理時間、異議申し立てと取り消し、当局からの命令を公表します。

## 9. 未成年者と重大な違法コンテンツ

手続は[最低年齢ポリシー](/idade)に定めています。モデレーションが通報を確認し次第コンテンツを非表示にし、証拠を法定の期間保全し、当局に通報し(ブラジルでは連邦警察とSaferNet、米国ではNCMECのCyberTipline)、投稿した者はネットワークから去ります。このようなものを見つけたコミュニティのモデレーターは、理由を「未成年者」または「違法」としてRovemarkに通報します。複製を保管せず、他人に渡しません。

## 10. 画像、動画、編集

**事前の審査なし。** 画像と動画は、誰の承認もなく、自動スキャンもなく公開されます。実際には、モデレーションが違法な画像や動画を知るのは、誰かが通報したときです。そのため、「通報」ボタンはすべてのメディアにあり、アカウントなしで使えます。理由は[ハウスルール](/regras)に、期限は第4条に記載しています。

**メディアの削除によって行われること:**

1. ファイルは当社のストレージから削除されます。
2. 同じファイルは、以後どのアカウントからも拒否されます。
3. 削除は、ファイルを表示することなく、モデレーションの公開記録に記載されます。
4. 公開物には、メディアが削除された旨の表示が付きます。
5. ブラウザや中継サーバーのキャッシュにある複製は、5分以内に消えます。

異議申し立てまたは反対通知がまだ可能な間、モデレーションはファイルをブロックするだけにとどめることがあります。ファイルは表示されなくなり、最終決定まで保管されます。重大な犯罪の場合は、ファイルが削除される前に、第9条に定めるとおり証拠が保全されます。

**編集の履歴。** 投稿者は公開したものを編集でき、バージョンの履歴は公開されます。編集されたコンテンツへの通報は、現在の内容と以前の内容の両方を対象とし、通報された後に編集しても事案は終了しません。削除が個人データまたは違法性を理由とする場合、**モデレーションは履歴全体を削除します**。現在のバージョンだけではありません。

## 11. 非公開のメッセージとイベント

**非公開のメッセージ**(機能がオンになった後)。メッセージはエンドツーエンドで暗号化されており、モデレーションはそれを読むことができません。モデレーションが対応するのは、メッセージを受け取った人がそれを通報した場合だけです。通報によって、そのメッセージの文章が、送信者が署名したものであることの証明とともにモデレーションに開示され、会話のそれ以外の部分は開示されません。会話のリクエストの文章は暗号化されておらず、モデレーションはそれを見ることができます。通報されたメッセージに基づいて、モデレーションは送信者に対して第3条に定める措置をとることができます。

**イベント。** イベントは他のコンテンツと同じコンテンツです。「通報」ボタンがあり、非表示または削除の対象になります。Rovemarkは、イベントが本物かどうかも、誰が主催しているかも確認しません。詐欺、待ち伏せ、または未成年者をおびき寄せるために使われたイベントは、場合に応じて、詐欺、脅迫、またはグルーミングとして扱います(第4条)。

## 12. 本ポリシーが約束しないこと

- すべての違反が発見されること。モデレーションは通報に依存しており、見逃しと過剰な対応の両方の誤りを犯します。
- 画像や動画が公開される前にRovemarkの誰かが見たこと。見ていません。
- 当社が非公開のメッセージを読めること。当社に見えるのは、誰かが通報したメッセージだけです。
- 複数の人による再審査。現在、人によるモデレーションは1人で行っています。
- 削除されたものが第三者の複製から消えること。
- 他の人が運営する別のリレーがこれらの規則に従うこと。
